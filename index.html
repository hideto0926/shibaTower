ぐらぐら物理Wobbly physics

輪郭でカクッと噛み合う。They mesh along real outlines.

当たり判定は画像の輪郭をそのままトレース。だから駒どうしが本物みたいに噛み合って、積み方しだいでタワーは高くも、危うくも。左右に動かして、くるっと回して、ベストな角度でそっと重ねましょう。 Collisions trace each image's real silhouette, so blocks interlock like the real thing. Slide, rotate, and gently place each one — how you stack decides how tall (and how risky) it gets.

  • アルファ輪郭でリアルに噛み合うAlpha-outline collision
