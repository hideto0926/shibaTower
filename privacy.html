SHIBA TOWER

プライバシーポリシー

最終更新日：2026年8月14日

SHIBA TOWER（以下「本アプリ」）は、秋吉秀信（以下「開発者」）が提供する iOS ゲームアプリです。本ポリシーでは、本アプリが取り扱う情報について説明します。本アプリは、ユーザーの写真を外部に送信することは一切ありません。

1. 取り扱う情報

  • 写真：ゲームの「駒」を作るためにユーザーが選択、または写真ライブラリからアクセスした画像。被写体（人物・ペット）の検出および切り抜きを含むすべての画像解析は、Apple の Vision フレームワーク等を用いてユーザーのデバイス上でのみ実行されます。写真やそこから得られたデータが、外部サーバーや第三者のサービスへ送信・共有されることは一切ありません。処理済みの切り抜き画像はゲームを速く動かすためにデバイス内にキャッシュされます。
  • スコア（Game Center）：ランキング機能を利用する場合、積んだ「個数」と「高さ」のスコア数値のみを Apple の Game Center に送信します。送信は Game Center にサインインしているときの任意機能です。写真や画像データが Game Center に送信されることはありません。
  • 記録・設定：ベスト記録・プレイ履歴・各種設定（モード、効果音の ON/OFF など）は、デバイス内にのみ保存されます。外部には送信されません。

2. 顔データの取り扱い（Face Data）

本アプリは、崩れたタワーの画像を共有する際に、写真内の顔を自動でぼかすため、Apple の Vision フレームワークを用いて顔の位置（矩形領域）のみをデバイス上で検出します。

  • 収集する顔データ：検出されるのは画像内の顔の位置を示す座標（バウンディングボックス）のみです。本アプリは顔認識・個人識別を行わず、顔の特徴量・顔認証テンプレート・生体情報（faceprint）を一切作成・収集しません。
  • 利用目的：共有画像内の顔にぼかしを適用するためだけに使用します。
  • 処理場所：顔の検出はすべてユーザーのデバイス上（オンデバイス）で完結します。外部サーバーや Apple・その他の第三者へ顔データが送信・共有されることはありません。
  • 保存・保持期間：検出した顔の位置情報は画像処理中にメモリ上で一時的に使用されるのみで、処理完了後ただちに破棄されます。顔データがデバイス内外に保存・保持されることはありません。

English: The app uses Apple's Vision framework on-device to detect only the location (bounding boxes) of faces in the user's photos, solely to apply a blur over them when sharing a tower image. The app does not perform face recognition or identification, and does not create or collect any faceprints, facial feature templates, or other biometric data. All detection happens entirely on-device; no face data is ever transmitted to or shared with any third party, including Apple. The detected face locations exist only transiently in memory during processing and are discarded immediately afterward — no face data is stored or retained anywhere.

3. 写真ライブラリへのアクセス

本アプリは、ゲームの駒を作るために写真ライブラリへのアクセス許可を求めることがあります。読み込まれた画像はすべてデバイス上で処理され、外部へ送信されることはありません。アクセスは iOS の設定からいつでも変更できます。

4. 情報の利用目的

  • 写真から駒を生成するための切り抜き・判定処理（すべてデバイス上で完結）
  • ランキング（個数・高さ）の登録・表示
  • ベスト記録・プレイ履歴・設定の保存

5. 第三者への提供

開発者は、法令に基づく場合を除き、ユーザーの個人情報を第三者に提供しません。本アプリは以下の Apple のサービスを利用します。

  • Apple Inc.（App Store、Game Center） — プライバシーポリシー

Game Center へはランキング用のスコア数値のみが送信されます。写真・画像・顔データが Apple その他の第三者へ送信されることはありません。本アプリは広告 SDK や解析 SDK、外部の AI／クラウド API を使用していません。

6. データの保存・セキュリティ

本アプリが処理する写真はデバイス外に送信されません。切り抜き・顔検出を含むすべての画像処理はデバイス上で完結し、写真・顔データが外部に保存・送信されることはありません。Game Center のスコアは Apple のサーバーで安全に管理されます。

7. お子様のプライバシー

本アプリは 13 歳未満のお子様を対象としていません。13 歳未満の方の個人情報を意図的に収集することはありません。

8. ポリシーの変更

本ポリシーは必要に応じて更新することがあります。重要な変更がある場合はアプリのアップデート時にお知らせします。
